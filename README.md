# code-with-me
Learning to code one project at a time.
1. Rock Paper Scissors

A game where a user plays against the computer. It tracks scores and saves them using JSON.

Concepts: Loops, conditionals, dictionaries, random module and JSON.

2. Password Hashing Demo

An educational program that validates a dummy password and generates a SHA-256 hash using Python's hashlib module.

Concepts: String commands, any(), loops, lists, validation and cryptographic hashing.
